Generated by gateway or cloud when a risk is confirmed.

```json
{
  "schema_version": "1.0",
  "packet_type": "ALERT",
  "alert_id": "ALT-20260824-001",

  "source": "GATEWAY",
  "gateway_id": "LG-GW-PAT-01",
  "alert_level": "RED",
  "alert_type": "FLOOD",
  "confidence_score": 0.87,
  "hazard": {
    "type": "FLOOD",
    "subtype": "FLASH_FLOOD",
    "description": "Rapid water level rise detected upstream",
    "estimated_impact_time_min": 45,
    "affected_area": {
      "center_lat": 25.6200,
      "center_lng": 85.1400,

    "model_layer": "GATEWAY",
    "flood_probability": 0.87,
    "predicted_peak_level_m": 3.8,

  },
  "recommended_actions": [
    "Evacuate low-lying areas within 5km radius",
    "Alert downstream villages",
    "Notify NDRF team"
  ],
  "status": "ACTIVE",
  "acknowledged_by": null,
  "acknowledged_at": null,
  "resolved_at": null
}
```

**Alert levels (standardized):**

| Level | Code | Color | Meaning | Action |
|-------|------|-------|---------|--------|
| 1 | `GREEN` | 🟢 | Normal | No action |
| 2 | `YELLOW` | 🟡 | Watch | Monitor closely, advisory issued |
| 3 | `ORANGE` | 🟠 | Warning | Prepare for action, authorities notified |
| 4 | `RED` | 🔴 | Emergency | Immediate action, evacuation may be needed |

**Alert types:**

| Code | Hazard |
|------|--------|
| `FLOOD` | River flood, flash flood, urban waterlogging |
| `AIR_QUALITY` | PM2.5/PM10 above safe limits |
| `FIRE` | Forest fire / smoke event |
| `EXTREME_HEAT` | Heat wave conditions |
| `LANDSLIDE` | Soil instability detected |
| `INDUSTRIAL_LEAK` | Gas / chemical leak |
| `WATER_CONTAMINATION` | Water quality degradation |

### 1.5 Command Packet (Cloud → Gateway → Node)

For remote commands (model update, config change, restart).

```json
{
  "schema_version": "1.0",
  "packet_type": "COMMAND",
  "command_id": "CMD-20260824-001",
  "target_type": "NODE",
  "target_id": "LG-NODE-PAT-003",
  "via_gateway": "LG-GW-PAT-01",
  "command": "UPDATE_MODEL",
  "payload": {
    "model_url": "https://lookoutgrid.com/models/flood-v3-q8.tflite",
    "model_version": "flood-v3-q8",
    "model_hash_sha256": "a1b2c3..."
  },
  "issued_by": "admin@lookoutgrid.com",
  "issued_at": "2026-08-24T13:00:00+05:30"
}
```


| Category | Values |
|---|---|
| **Node types** | `FLOOD`, `AIR_QUALITY`, `FIRE`, `MULTI` |
| **Alert levels** | `GREEN`, `YELLOW`, `ORANGE`, `RED` |
| **Alert types** | `FLOOD`, `AIR_QUALITY`, `FIRE`, `EXTREME_HEAT`, `LANDSLIDE`, `INDUSTRIAL_LEAK`, `WATER_CONTAMINATION` |
| **Command types** | `UPDATE_MODEL`, `UPDATE_CONFIG`, `RESTART`, `CALIBRATE`, `SLEEP`, `WAKE`, `FACTORY_RESET` |
| **Power sources** | `SOLAR`, `BATTERY`, `MAINS` |
| **Communication types** | `LORA`, `BLE`, `WIFI`, `ESPNOW` |
